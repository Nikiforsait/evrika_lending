# UI copy glossary (Russian)

Use these terms everywhere, in the same form. Address the learner with «ты».

| Term | Use | Avoid |
|---|---|---|
| **стрик** | Days in a row with at least one task. «Стрик: 7 дней» | серия, страйк |
| **заморозка** | Token that saves the streak for one missed day | фриз |
| **XP** | Experience points. Always Latin, after the number: «+10 XP» | опыт, очки опыта |
| **уровень** | Numeric level from XP: «Уровень 4» | лвл |
| **Новичок / Уверенный / Эксперт** | XP tiers shown next to the level | — |
| **мастерство** | Per-topic mastery 0–100%, shown as низкий / средний / высокий | знание, скилл |
| **прогноз** | Predicted score: «Прогноз: 14 / 19» | оценка (implies a grade) |
| **дуэль** | Asynchronous 5-task match against a classmate | битва, матч |
| **лига / лидеры класса** | Weekly XP ranking | рейтинг |
| **тренировка / тренажёр** | Adaptive practice session / a practice entry point | урок |
| **диагностика** | The 19-question starting test (one per task number) | экзамен, контрольная |
| **справочник** | Handbook of concepts, formulas and personal notes | учебник |
| **карточки** | Spaced-repetition formula cards | флешкарты |

## Voice

- Short, plain verbs in sentence case. Buttons say what happens: «Ответить», «Проверить», «Начать тренировку».
- An action keeps its name through the flow (button «Пригласить» → status «Ссылка скопирована»).
- Errors explain what to check, not that something is wrong: «Сверьте процент с условием задачи.»
- Feedback is encouraging but honest: «Верно!», «Не совсем», never «Ошибка!».
- Numbers: Russian formatting — thin space for thousands (5 000), decimal comma (0,8).
- Money is always neutral units: «у.е.». No currency symbols, countries or exam names anywhere in the UI.
